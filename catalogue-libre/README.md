# Catalogue libre : cours et formations sous licence ouverte

Ce dossier contient 41 PDF téléchargés depuis Wikimedia Commons, avec leur licence et leur source.
Chaque fichier est listé dans [manifest.json](manifest.json) (titre, licence, auteur, empreinte SHA-1, URL source).

Seules les licences compatibles avec une utilisation commerciale avec attribution sont retenues :
CC BY, CC BY-SA, CC0, GFDL, domaine public. Les licences non commerciales (NC) et sans dérivation (ND) sont exclues.

## Obligations

- **CC BY-SA et GFDL** : garder l'attribution et partager les dérivés sous la même licence.
- **CC BY** : garder l'attribution.
- **Domaine public et CC0** : pas d'obligation légale, l'attribution reste recommandée.

Les descriptions importées dans le catalogue reprennent la licence, l'auteur et la source de chaque fichier.

## Import dans le catalogue

Le script [recruiter-web/scripts/import-free-pdfs.mjs](../recruiter-web/scripts/import-free-pdfs.mjs) envoie ces PDF à `POST /api/pdf`.
Sans `--apply`, il ne fait qu'un essai à blanc.

```bash
node recruiter-web/scripts/import-free-pdfs.mjs --dir catalogue-libre/pdf --manifest catalogue-libre/manifest.json
```
